# Uni-Planung: Künstliche Intelligenz & Kognitive Informatik (B.Sc.)

Interaktiver Studienplaner und Fortschrittstracker für den Bachelorstudiengang **Künstliche Intelligenz und Kognitive Informatik (1-Fach)** an der **Universität Bielefeld**.

## 🚀 Funktionen

- 📋 **Offizieller Bielefelder Modulkatalog**: Alle Pflicht-, Wahlpflicht-, MiKE- und Ergänzungsmodule mit LP, Prüfungsformen (SL, bPr, uPr) und EkVV-Direktlinks vorinstalliert.
- ☑️ **1-Klick Status-Tracking**: Hake erledigte Kurse ab (`Abgeschlossen`), plane kommende Semester (`In Planung`) oder behalte offene Module im Blick.
- ⚡ **Echtzeit-Fortschritt & LP-Zähler**: Automatische Berechnung der Gesamtleistungspunkte (Ziel: 180 LP) und Notendurchschnitt (GPA).
- 📅 **Semester-Roadmap (1. - 6. Sem)**: Übersicht über den empfohlenen Studienverlauf mit LP-Last pro Semester (Ziel: ~30 LP / Sem).
- 🔍 **Echtzeit-Suche & Filter**: Schnellsuche nach Modulkürzeln (z.B. `39-Inf-ML`), Modulnamen und Kategorien.
- 📝 **Notizen & Noten**: Trage deine Noten, Klausurtermine und persönliche Notizen für jedes Modul ein.
- ➕ **Eigene Module anlegen**: Ergänze individuelle Seminare, Sprachkurse oder externe Leistungen.
- 💾 **Automatisches Speichern & Export/Import**: Alle Eingaben werden lokal im Browser (`localStorage`) gespeichert und können als JSON exportiert werden.
- 🌓 **Dark & Light Mode**: Modernes Farbschema mit Themeswitcher.

## 💻 Schnellstart

Öffne einfach die Datei `index.html` in einem modernen Webbrowser (Chrome, Edge, Firefox, Safari):

```bash
# Direkt im Browser öffnen:
index.html
```
